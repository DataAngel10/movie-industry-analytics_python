# Movie Industry Analytics: Budget vs Gross Revenue Analysis
*Python Portfolio Project*

## Project Overview
An exploratory data analysis (EDA) in Python examining the relationship between movie budgets and gross revenues, covering data cleaning, 
analysis, and statistical correlation.

## 🛠️ Tools & Libraries
- **Language:** Python
- **Libraries:** Pandas, NumPy, Seaborn, Matplotlib

## 🔍 Key Steps & Workflow
1. **Data Inspection:** Loading the dataset and reviewing data types, missing values, and structure.
2. **Data Cleaning:** Handling duplicates, formatting data fields, and cleaning anomalies.
3. **Exploratory Data Analysis (EDA):** Examining distributions, top genres, and high-performing production companies.
4. **Correlation Analysis:** Evaluating the statistical relationship between budget and gross revenue using visualization and correlation
   matrices.
